# Préparation mobile pour Easy Life

## Objectif
Ce document prépare l’application pour une future publication mobile et une éventuelle soumission à l’App Store.

## Étapes déjà réalisées
- Application Next.js fonctionnelle
- Manifest PWA ajouté
- Icônes Apple/PWA présentes
- Structure Capacitor ajoutée pour un packaging iOS futur

## Prochaines étapes
1. Installer les dépendances Capacitor
2. Générer le projet iOS avec `npx cap add ios`
3. Configurer l’App ID Apple et les profils de provisionnement
4. Tester sur un vrai iPhone
5. Préparer les captures d’écran et la description App Store

## Commandes utiles
```bash
npm install
npx cap sync
npx cap open ios
```
