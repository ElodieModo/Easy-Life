# Checklist App Store - Easy Life

## 1. Préparation de l’app
- [ ] Vérifier que l’application fonctionne correctement sur iPhone
- [ ] Tester la connexion/déconnexion et la persistance de session
- [ ] Vérifier les permissions demandées et leur nécessité
- [ ] Valider le fonctionnement hors ligne/avec réseau intermittent
- [ ] Vérifier les erreurs console et les logs d’authentification

## 2. Ressources Apple
- [ ] Créer un identifiant d’app Apple
- [ ] Créer un profil de provisionnement
- [ ] Générer un certificat de distribution
- [ ] Ajouter les icônes iOS conformes aux guidelines Apple
- [ ] Ajouter un splash screen ou écran de lancement
- [ ] Configurer le bundle identifier

## 3. Métadonnées App Store
- [ ] Nom de l’app : Easy Life
- [ ] Sous-titre : Organisation familiale
- [ ] Description courte
- [ ] Description complète
- [ ] Mots-clés pertinents
- [ ] Captures d’écran iPhone
- [ ] URL de support
- [ ] URL de confidentialité

## 4. Conformité légale
- [ ] Politique de confidentialité en français
- [ ] Conditions d’utilisation en français
- [ ] Vérifier l’âge minimum de la cible
- [ ] Vérifier le contenu sensible ou familial

## 5. Soumission
- [ ] Créer un compte développeur Apple
- [ ] Ajouter l’app dans App Store Connect
- [ ] Soumettre la build via Xcode ou Transporter
- [ ] Remplir les informations de l’app
- [ ] Envoyer pour révision
