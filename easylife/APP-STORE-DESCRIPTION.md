# Description App Store - Easy Life

## Nom de l’app
Easy Life

## Sous-titre
Organisation familiale

## Description courte
L’application familiale simple et chaleureuse pour organiser le quotidien : planning, courses, menu, notes et adresses utiles.

## Description complète
Easy Life est une application familiale pensée pour simplifier le quotidien des parents et des enfants.

Avec Easy Life, vous pouvez :
- organiser le planning des enfants,
- créer des listes de courses partagées,
- préparer le menu de la semaine,
- conserver des notes et adresses utiles,
- centraliser les informations importantes de la famille.

Une interface claire, chaleureuse et facile à utiliser, idéale pour garder toute la famille synchronisée au quotidien.

## Mots-clés
famille, organisation, planning, courses, menu, notes, quotidien
